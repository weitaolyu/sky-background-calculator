Sky Background Calculator

A compact web notebook for estimating single-pixel background power from sky emission, atmosphere, telescope optics, and instrument emission. Built for MKID-oriented workflows and SCUBA-2-style background reasoning.

What this project does
  • Derives the path from an external background temperature to single-pixel absorbed power.
  • Separates incident power from absorbed power so the output can be used consistently in detector models.
  • Provides a quick calculator with tunable transmission, emissivity, bandpass, and etendue parameters.

Project overview

This site presents a clear chain from external background brightness to detector-ready absorbed power. It is intended for quick estimation, documentation, and reproducible reasoning when comparing sky conditions or translating optical power into MKID quasiparticle inputs.

Notes

Important: The calculator is a simplified model. For precision work, use measured bandpass, the actual optical chain, and detector absorption consistent with your device model.
