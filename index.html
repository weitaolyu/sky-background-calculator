从 Tbg 到单个 pixel 接收的功率

从黑体辐射、天空与大气的辐射传输，到单像素的 throughput、滤波器和最终吸收功率。本文中的功率均指单位时间接收的能量，单位为 W。

1. 先定义功率平面

必须先说明 P 是在哪个位置定义的。常见的三个平面是：

功率名称位置是否可直接进入 MKID quasiparticle 模型
Poutside望远镜/大气上方的入射功率不能，仍需乘大气和仪器传输率
Pdetector incident到达探测器表面的功率还需乘吸收率
Pabs真正被探测器吸收的功率通常应使用这个量
核心提醒：本文最后得到的 Ppixel 如果被定义为 absorbed power，才可以直接代入 MKID 的 quasiparticle 产生模型。若输入是 incident power，需要额外乘探测器吸收率。

2. Tbg 产生的黑体光谱

温度为 T 的理想黑体，其单位频率、单位面积、单位立体角的光谱辐射亮度由 Planck 定律给出：

$$B_\nu(T)=\frac{2h\nu^3}{c^2}\frac{1}{\exp\!\left(h\nu/k_{\rm B}T\right)-1}.$$

如果使用波长变量，必须同时变换积分变量：

$$B_\lambda(T)=\frac{2hc^2}{\lambda^5}\frac{1}{\exp\!\left(hc/\lambda k_{\rm B}T\right)-1}, \qquad B_\nu\,d\nu=B_\lambda\,d\lambda.$$

因此不能把 Bν 直接对 dλ 积分；频率表达式和波长表达式的 Jacobian 不同。

3. 从外部天空到望远镜入口

这里的 Tbg 应理解为大气上方的外部背景。如果只考虑宇宙微波背景，应取 Tbg = TCMB = 2.725 K；它不是地面望远镜看到的总天空温度。

若天空背景可以近似为温度 Tbg 的黑体，并且大气温度为 Tatm，大气频率透过率为 tν，则地面看到的天空辐射可写成一层均匀大气的近似：

$$I_{\nu,\rm sky}=t_\nu B_\nu(T_{\rm bg})+\left(1-t_\nu\right)B_\nu(T_{\rm atm}).$$

第一项是外部背景透过大气后的部分；第二项是大气吸收外部辐射后产生的自身热发射。这个形式来自 Kirchhoff 定律：对不透明度为 1 − tν 的热层，其发射率近似为 1 − tν。如果你已经有了包含大气发射的有效天空亮度 Iν, sky，就不能再把大气发射项加一次。

透过率通常由光学厚度给出：

$$t_\nu(X)=\exp\left[-\tau_\nu X\right],$$

其中 X 是 air mass。天顶观测时 X ≃ 1，因此 τν = −ln tν,0。例如 t450 = 0.40 时，τ450 = 0.916。

4. 加入望远镜和仪器自身发射

望远镜和每个温暖光学元件都可能发射辐射。若用一个简化的望远镜项表示：

$$I_{\nu,\rm in}=I_{\nu,\rm sky}+\epsilon_{\rm tel}B_\nu(T_{\rm tel})+\sum_i I_{\nu,i},$$

其中 εtel 是���远镜有效发射率。对多个串联光学元件，严格计算需要逐层进行辐射传输；每一层的贡献大致具有：

$$dI_{\nu,i}\sim \epsilon_i B_\nu(T_i)\times(\text{位于该元件之后的传输率}).$$

所以 SCUBA-2 的背景不是单独的天空黑体，而是 sky、atmosphere、telescope 和 instrument emission 的总和。

5. 单个 pixel 如何接收辐射

单像素接收功率的最一般形式是：

$$P_{\rm pix}=\int_{\nu_1}^{\nu_2}\int_{\Omega_{\rm pix}}A_{\rm eff}(\nu,\Omega)\,\eta_{\rm pre}(\nu,\Omega)\,I_{\nu,\rm in}(\nu,\Omega)\,d\Omega\,d\nu.$$

这里：

  • Aeff：像素看到的有效 collecting area；
  • Ωpix：单像素 beam/FOV 的立体角；
  • AΩ：单像素的 optical throughput 或 etendue；
  • ηpre：滤波器、窗口、反射镜、波导等在探测器吸收之前的效率；
  • ν₁、ν₂：实际通带边界。

如果背景在单像素视场内均匀，且 A、η 可以近似与角度无关：

$$P_{\rm pix}\simeq A\Omega_{\rm pix}\int_{\nu_1}^{\nu_2}\eta_{\rm pre}(\nu)I_{\nu,\rm in}(\nu)\,d\nu.$$

6. 从 incident power 到 absorbed power

若探测器吸收率为 ηabs(ν)，则真正吸收的功率是：

$$P_{\rm abs}=A\Omega_{\rm pix}\int_{\nu_1}^{\nu_2}\eta_{\rm pre}(\nu)\eta_{\rm abs}(\nu)I_{\nu,\rm in}(\nu)\,d\nu.$$

定义总光学效率 ηopt(ν) = ηpre(ν)ηabs(ν)，则：

$$\boxed{P_{\rm abs}=A\Omega_{\rm pix}\int_{\nu_1}^{\nu_2}\eta_{\rm opt}(\nu)I_{\nu,\rm in}(\nu)\,d\nu.}$$

若通带内的效率和辐射亮度都近似常数：

$$P_{\rm abs}\simeq A\Omega_{\rm pix}\,\eta_{\rm opt}\,I_{\nu,\rm in}(\nu_0)\,\Delta\nu.$$

这只是窄带估算。对于 SCUBA-2，应优先使用实测 bandpass η(ν)，而不是只使用中心频率和矩形带宽。

7. AΩ 与 FOV 的关系

总相机 FOV 不应代入单像素功率。单像素功率只使用该像素自己的 Ωpix：

$$\Omega_{\rm pix}\simeq\frac{\pi\theta_{\rm beam}^2}{4\ln2} \quad \text{(Gaussian beam)},$$

其中 θbeam 用弧度表示。对于理想单模系统，还常有：

$$A\Omega\simeq\lambda^2.$$

这解释了为什么扩展背景下，单像素功率主要由单像素的模式数和 throughput 决定，而不是由整台相机的几十平方 arcmin FOV 决定。

8. 与 SCUBA-2 Table 1 的对应

SCUBA-2 Table 1 给出的 450 μm 背景功率为 70--120 pW，850 μm 为 7--16 pW。论文明确说明这些数值来自一个继承自 SCUBA 的详细背景模型：

  • 最佳天气采用 450 μm 和 850 μm 的天顶透过率分别为 40% 和 85%；
  • 最差天气采用 3% 和 40%；
  • 模型背景包括 sky、telescope 和 instrument；
  • SCUBA-2 的滤波器半功率带宽约为 32 μm 和 85 μm；
  • 论文给出的窗口、滤波器和 detector absorption 的净传输率约为 40%。

因此 Table 1 的计算逻辑可以表示为：

$$T_{\rm bg},\ t_\nu,\ T_i,\ \epsilon_i,\ \eta(\nu),\ A\Omega_{\rm pix} \ \longrightarrow\ P_{\rm bg,pix}.$$
可复现性边界：论文正文没有列出每个光学元件的温度、发射率、完整 bandpass 和 AΩ 数值，所以不能只靠 Table 1 的文字精确反推出 70 pW。要精确复现，需要论文所引用的详细模型或 Hollister (2009) thesis。

9. 最适合 MKID 的实现形式

对数值频率网格，建议直接计算：

$$P_{\rm abs}\approx A\Omega\sum_j \eta_{\rm opt}(\nu_j)I_{\nu,\rm in}(\nu_j)\Delta\nu_j.$$

然后把 Pabs 代入 quasiparticle 模型，例如：

$$n_{\rm qp}=\sqrt{n_{\rm base}^2+\frac{\eta_{\rm pb}P_{\rm abs}}{\Delta R_{\rm qp}V}}.$$

这里的 Pabs 必须和 ηpb 的定义一致：如果 ηpb 描述的是被吸收功率转化为 quasiparticle 能量的比例，就不能再把 detector absorption 重复乘一次。

10. 简化数值估算器

计算器先计算 CMB 和大气辐射，再加入望远镜和仪器自身热发射，得到到达 pixel 的总亮度；然后在中心频率处反解等效天空温度，最后计算单 pixel 吸收功率。默认值只是典型估算，不代表 SCUBA-2 的完整光学模型。

计算公式
$$I_{\nu,\rm sky}=t_\nu B_\nu(T_{\rm CMB})+(1-t_\nu)B_\nu(T_{\rm atm})$$
$$I_{\nu,\rm tel}= (1-\epsilon_{\rm tel})I_{\nu,\rm sky}+\epsilon_{\rm tel}B_\nu(T_{\rm tel})$$
$$I_{\nu,\rm det}=t_{\rm inst}I_{\nu,\rm tel}+\epsilon_{\rm inst}B_\nu(T_{\rm inst})$$
$$B_\nu(T_{\rm sky,eff})=I_{\nu,\rm det}$$
$$P_{\rm abs}=A\Omega\,\eta_{\rm abs}\,I_{\nu,\rm det}\,\Delta\nu$$
$$\Delta\nu\simeq\frac{c}{\lambda_0^2}\Delta\lambda$$
请输入参数后计算。
